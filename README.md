# bunbun-puzzle
🐰🎀 Play here!: https://marthahere.github.io/bunbun-puzzle/

BunBun is a little puzzle game where you place cute bunnies on a colorful 5×5 grid while following a few simple rules.

This is a personal project inspired by the puzzle mechanics of the mobile game Meowdoku by Oakever Games. I really enjoy playing it and I find the idea behind its rules interesting, so I wanted to make my own version with bunnies and figure out how to build the game logic myself.

The game uses a 5×5 board with rules like one bunny per row and column, one bunny per color and bunnies not being allowed to touch.

One of the main things I wanted to experiment with was having JavaScript generate a new puzzle/solution for each round instead of manually making every level.

It's a pretty simple game that I mostly made to learn, experiment and have fun! 💗
